# Sprite Cutter

Инструмент для автоматической нарезки спрайтов из единого изображения (спрайт-листа) на отдельные PNG-файлы с прозрачным фоном, а также для сборки этих кадров в анимированные GIF.

## Возможности

- Загрузка изображения со спрайтами (PNG, JPEG и др.)
- Выбор цвета фона по одной точке (левый верхний угол по умолчанию)
- Автоматическое выделение всех связных областей не-фона (8-связность)
  > *Из минусов: если куски спрайта отделены друг от друга (например, разорваны фоном), они сохранятся как отдельные изображения, даже если по смыслу должны быть вместе.*
- Группировка спрайтов в анимации на основе их расположения на листе (вертикальные и горизонтальные пороги настраиваются)
- Сохранение каждого спрайта в отдельный PNG с прозрачностью
- **Создание анимированных GIF** из нарезанных кадров (по одному GIF на каждую анимацию)
- Графический интерфейс на Fyne

## Установка и запуск

### Готовый исполняемый файл (рекомендуется)

Скачай последнюю версию `sprite-cutter-gui.exe` из [Releases](https://github.com/Bybba/sprite-cutter/releases) и запусти. Никаких дополнительных зависимостей не требуется.

### Сборка из исходников

Если хочешь собрать программу самостоятельно:

1. Установи [Go](https://golang.org/dl/) (версия 1.21 или новее)
2. Установи [MinGW-w64](https://www.mingw-w64.org/) с **posix thread model** и **seh exception handling** (только для GUI)
3. Клонируй репозиторий:
   ```bash
   git clone https://github.com/Bybba/sprite-cutter.git
   cd sprite-cutter
   ```
4. Собери нужные компоненты:

   - **GUI-версия** (нарезка спрайтов):
     ```bash
     go mod tidy
     go build -ldflags -H=windowsgui -o sprite-cutter-gui.exe ./cmd/sprite-cutter-gui
     ```

   - **Консольная версия** (нарезка спрайтов):
     ```bash
     go build -o sprite-cutter-cli.exe ./cmd/sprite-cutter
     ```

   - **GIF-maker** (сборка анимаций):
     ```bash
     go build -o gif-maker-cli.exe ./cmd/gif-maker
     ```

5. Запусти полученные `.exe` файлы.

## Использование (GUI)

1. Нажми **«Обзор…»** рядом с полем «Входной файл» и выбери спрайт-лист.
2. Укажи папку для сохранения результатов (по умолчанию `images/output`).
3. При необходимости измени **вертикальный** и **горизонтальный** пороги группировки (это поможет правильно отделить одну анимацию от другой).
4. Нажми **«Нарезать спрайты»**.
5. После завершения в выбранной папке появятся файлы `sprite_01_01.png`, `sprite_01_02.png`, … (группы и кадры).
6. Для создания GIF-анимаций используй консольную утилиту `gif-maker-cli.exe` (см. ниже).

> **Примечание:** цвет фона определяется по пикселю в левом верхнем углу (координаты 0,0). Если фон в другом месте, укажи другие координаты через CLI (флаг `-bg`).

## Консольная версия (нарезка спрайтов)

Позволяет нарезать спрайты без графического интерфейса, удобно для автоматизации.

### Сборка:

```bash
go build -o sprite-cutter-cli.exe ./cmd/sprite-cutter
```

### Использование:

```bash
sprite-cutter-cli.exe -input <путь_к_изображению> -output <папка_для_спрайтов> -bg <x,y> -threshold <порог> -vert <верт.порог> -horiz <гор.порог>
```

**Параметры:**

- `-input` — путь к исходному спрайт-листу (обязательно)
- `-output` — папка для сохранения результатов (по умолчанию `images/output`)
- `-bg` — координаты точки фона в формате `x,y` (по умолчанию `0,0`)
- `-threshold` — порог схожести цвета (0-765, по умолчанию 50)
- `-vert` — вертикальный порог группировки в пикселях (по умолчанию 20)
- `-horiz` — горизонтальный порог группировки в пикселях (по умолчанию 50)

**Пример:**

```bash
sprite-cutter-cli.exe -input images/input/zoro.png -output images/output -bg 0,0 -threshold 50 -vert 20 -horiz 50
```

После выполнения в `images/output` появятся файлы вида `sprite_XX_YY.png`, где `XX` – номер анимации (группы), `YY` – номер кадра.

## Создание GIF-анимаций

После того как спрайты нарезаны и сгруппированы, можно собрать каждую группу в отдельный анимированный GIF.

### Сборка GIF-maker:

```bash
go build -o gif-maker-cli.exe ./cmd/gif-maker
```

### Использование:

```bash
gif-maker-cli.exe -input <папка_с_PNG> -output <папка_для_GIF> -delay <задержка> -loop <повторы>
```

**Параметры:**

- `-input` — папка, содержащая файлы `sprite_XX_YY.png` (обычно та же, что и `-output` у нарезчика)
- `-output` — папка для сохранения GIF (будет создана автоматически)
- `-delay` — задержка между кадрами в сотых долях секунды (например, `10` = 0.1 сек, `20` = 0.2 сек). По умолчанию `10`.
- `-loop` — количество повторов: `0` = бесконечно, `-1` = один раз, положительное число = повторов+1. По умолчанию `0`.

**Пример:**

```bash
gif-maker-cli.exe -input images/output -output images/gifs -delay 10 -loop 0
```

После выполнения в папке `images/gifs` появятся файлы `animation_01.gif`, `animation_02.gif`, … – по одному на каждую анимацию. Кадры будут расположены в порядке возрастания номера кадра (вторая цифра в имени файла).

**Примечания по GIF:**

- Все кадры одной анимации автоматически приводятся к единому размеру (максимальному по группе) и центрируются.
- Используется глобальная палитра, что исключает артефакты.
- Прозрачный фон сохраняется.

## Как это работает (алгоритм нарезки)

1. Получает цвет фона по указанной точке.
2. Сканирует изображение, выделяя все связные области не-фона (используя 8-связность).
3. Для каждой области строит ограничивающий прямоугольник.
4. Группирует прямоугольники в анимации: сначала по вертикали (строки), затем внутри строки по горизонтальному разрыву. Пороги `-vert` и `-horiz` управляют чувствительностью.
5. Сохраняет каждую область как PNG с прозрачным фоном, имя `sprite_<группа>_<кадр>.png`.
