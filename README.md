# Sprite Cutter

## Инструмент для автоматической нарезки спрайтов из единого изображения (спрайт-листа) на отдельные PNG-файлы с прозрачным фоном.

### Возможности

- Загрузка изображения со спрайтами (PNG, JPEG и др.)
- Выбор цвета фона по одной точке (левый верхний угол по умолчанию)
- Автоматическое выделение всех связных областей не-фона (8-связность) (из минусов, если куски спрайта отделены то они сохранятся как отдельные изображения, даже если по смыслу они должны быть вместе)
- Сохранение каждого спрайта в отдельный PNG с прозрачностью
- Графический интерфейс на Fyne

#### Сборка из исходников

Если хочешь собрать программу самостоятельно:

1. Установи Go (версия 1.21 или новее): https://golang.org/dl/
2. Установи MinGW-w64 с posix thread model и seh exception handling: https://www.mingw-w64.org/
3. Клонируй репозиторий:
```bash
   git clone https://github.com/Bybba/sprite-cutter.git
```
4. Собери программу:
```bash
   go mod tidy
   go build -ldflags -H=windowsgui -o sprite-cutter.exe ./cmd/sprite-cutter-gui
```
5. Запусти полученный sprite-cutter.exe.

### Использование

1. Нажми «Обзор…» рядом с полем «Входной файл» и выбери спрайт-лист.
2. При необходимости укажи папку для сохранения результатов (по умолчанию images/output).
3. Нажми «Нарезать спрайты».
4. Дождись сообщения «Готово». Все спрайты появятся в выбранной папке с именами sprite_0000.png, sprite_0001.png и т.д.

Примечание: цвет фона определяется по пикселю в левом верхнем углу (координаты 0,0). Если фон в другом месте, измени исходный код или доработай программу под свои нужды.

### Консольная версия

Для любителей терминала или автоматизации есть консольная версия программы. Она находится в папке cmd/sprite-cutter и позволяет нарезать спрайты без графического интерфейса.

#### Сборка:

```bash
go build -o sprite-cutter-cli.exe ./cmd/sprite-cutter
```

#### Использование:

```bash
sprite-cutter-cli.exe -input <путь_к_изображению> -output <папка_для_спрайтов> -bg <x,y> -threshold <порог>
```

#### Параметры:

-input — путь к исходному спрайт-листу (обязательно)
-output — папка для сохранения результатов (по умолчанию images/output)
-bg — координаты точки фона в формате x,y (по умолчанию 0,0)
-threshold — порог схожести цвета (0-765, по умолчанию 50)

#### Пример:

```bash
sprite-cutter-cli.exe -input images/spritesheet.png -output my_sprites -bg 10,5 -threshold 60
```

### Как это работает

Алгоритм:

1. Получает цвет фона по указанной точке.
2. Сканирует изображение, выделяя все связные области не-фона (используя 8-связность).
3. Для каждой области строит ограничивающий прямоугольник.
4. Сохраняет область как PNG, заменяя фоновые пиксели на прозрачные.

### Зависимости

- Fyne — графический интерфейс
- Стандартные пакеты Go: image, image/color, image/png, os, path/filepath
